# MedVokabeln

Kostenlose, installierbare Lern-Web-App für medizinische und anatomische Fachbegriffe.

## GitHub Pages aktivieren
1. Öffne **Settings → Pages** im Repository.
2. Unter **Build and deployment** die Quelle **Deploy from a branch** wählen.
3. Branch **main**, Ordner **/(root)** auswählen und **Save** klicken.
4. Warte, bis GitHub Pages eine veröffentlichte Adresse anzeigt.

## Auf Android installieren
Öffne die veröffentlichte HTTPS-Adresse in Chrome. Im Menü **⋮** „App installieren“ oder „Zum Startbildschirm hinzufügen“ wählen.

## Funktionen
- Karteikarten mit Selbstbewertung
- Multiple-Choice-Quiz
- Suchbare Vokabelliste und Themenbereiche
- Lernfortschritt lokal speichern und als JSON exportieren
- Offline-Caching nach dem ersten Laden

Der Lernstand wird nicht synchronisiert und bleibt auf dem Gerät/im Browser. Die Vokabelliste ist ein Lernentwurf und sollte fachlich überprüft werden; die App ersetzt keine medizinische Fachliteratur oder Beratung.
